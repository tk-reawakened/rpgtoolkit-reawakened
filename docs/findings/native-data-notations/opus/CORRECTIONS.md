# Correction record (Opus, #1778), after the independent reviews

The **first pass is preserved unchanged** at `/private/tmp/tkr-1778-opus-first-pass.tar.gz` (parent-made snapshot). This page records what the four independent reviews (verification, edge, adversarial, structure) found in **my** tools and report. It records what I changed and which experiments I re-ran. Each check is executable: [`correction-checks.mjs`](../../../../tools/research/native-data-notations/opus/correction-checks.mjs) writes `results/correction-checks.json`. The corrected figures and claims are written through into [README.md](README.md), [mapping.md](mapping.md), [candidates.md](candidates.md) and [walkthrough.md](walkthrough.md); no superseded first-pass statement is left there.
