# Candidate facts and dispositions (Opus, #1778)

Part of the [Opus independent report](README.md). Every version below was installed and exercised on 2026-11-08, in isolation under `/private/tmp/tkr-1778-opus-experiments`. Nothing was added to workspace manifests or lockfiles. Licence data comes from the npm registry, Maven POMs or GitHub. Maintenance data is each repository's last push, read with `gh api repos/<repo>` on 2026-11-08.

"Exercised" means the experiment harness ran it on real projected cohort documents. Cells named in "Blocked / not available" record what was tried; they are not judgements of the notation. G6 refers to the [licence gate](../../../guardrails.md#g6--licence-gate).

## Track 2: SDLang (preliminary; promotion blocked)

| Item | Evidence |
|---|---|
| Spec | [sdlang.org](https://sdlang.org) (HTTP 200 on 2026-11-08) and the SDLang-D language guide. |
| Implementations | D: Abscissa/SDLang-D (last push 2023-04, licence NOASSERTION). Java: `com.singingbush:sdlang` 2.2.0, **LGPL-2.1, blocked by G6**. C#: SdlangSharp (MIT, last push 2021-09). JS/TS: `sdlang` 0.2.2 (ISC, 2022), a port of SdlangSharp. |
| Exercised | `sdlang` 0.2.2. Its ESM build cannot load in Node (extensionless imports), so it was bundled with esbuild. |
| Defects observed | `speed 0.3` prints as `speed 0`. `null` is rejected ("Unexpected token of type 20"). `;` separators are rejected. Binary values throw `TODO`. `2026/11/08` re-prints as `2026/11/00 06:00:00.000-GMT+0`. `toString()` does not re-escape quotes, so its output is invalid. |
| Disposition | **Blocked within the implementations surveyed:** the only JS/TS implementation found fails basic cases; the Java one is LGPL-2.1 (G6); the D and C# ones were not run and do not target the browser. Not promoted to the hands-on matrix. This is not a judgement of SDLang's syntax, which is close to KDL's node model. |
