# Connected editor mockup

Download [the interactive mockup](connected-editor.zip), extract it and open `connected-editor.html` in a browser. It opens in the program editor. Use the Game tree or the centered command palette to visit other documents. Edits last for the page session.

## Programs and references

Open Wander and intercept. Follow the reference to man.prg, then pirate.ene. Use Back to return. Select a scene outline entry to jump within the editable source. Open Command reference to search the sample commands. Used by links illustrate navigation to an owning document. The sample character assignment is illustrative. A production link requires a supported owner field.

## Boards and artwork

Open Brookvale. Pick Stonework in the board tileset selector, choose a brush, visit its tile artwork and return to the board. Compare Sheet and Tile focus. Use the Files and Game icons with the navigator folded.

## Character and battle resources

Open Mira Vale from Characters. Browse Trail Ward, Regeneration and Riverbank under Battle. Open their linked resources in document tabs. Use the shared inspector and theme controls across these views.

The mock records interaction design. Each issue's acceptance criteria and supported asset contracts govern implementation.
