# Hosting options for tk-reawakened.com

Compared on 2026-11-14. The owner has the domain. The DNS check returned Porkbun nameservers and Porkbun mail-forwarding MX records. The host choice is open.

Build the first site as a portable static deployment from the website repository. The build includes the landing pages, versioned docs and search index, and showcase entries. Its download page points to the official release artifacts. Publish a representative preview before connecting the production domain.

| Option | Fit for launch | Tradeoff |
| --- | --- | --- |
| GitHub Pages | Straightforward for a public website repository and can use the existing DNS provider. The first site can live here even if it links to a forum on another host. | Published site limit of 1 GB and a soft bandwidth limit of 100 GB per month. [Pages limits](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits) · [Custom domains](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site) |
| Cloudflare Workers Static Assets | Static requests are free and unlimited. Cloudflare also offers Git builds and previews. Cloudflare Pages supports Git-backed static deployments as another option. | Serving the apex directly requires a Cloudflare zone. A DNS move from Porkbun would need to carry over and verify the existing mail records. Workers limits a single static file to 25 MiB. [Static asset billing](https://developers.cloudflare.com/workers/static-assets/billing-and-limitations/) · [Workers custom domains](https://developers.cloudflare.com/workers/configuration/routing/custom-domains/) · [Workers Builds](https://developers.cloudflare.com/workers/ci-cd/builds/) · [Pages domains](https://developers.cloudflare.com/pages/configuration/custom-domains/) |
| Netlify | Deploy previews and built-in forms could help with submissions. The apex can use external DNS. | Production deploys and traffic consume credits. The free plan has a hard monthly credit cap. [Netlify plans](https://docs.netlify.com/manage/accounts-and-billing/billing/billing-for-credit-based-plans/credit-based-pricing-plans/) · [External DNS](https://docs.netlify.com/manage/domains/configure-domains/configure-external-dns/) |
| AWS Amplify Hosting | Managed hosting with support for external DNS. A fit if the project already wants to operate the site through an AWS account. | Metered builds, storage and data transfer beyond applicable allowances. The external DNS setup needs an apex alias record. [Amplify pricing](https://aws.amazon.com/amplify/pricing/) · [External DNS](https://docs.aws.amazon.com/amplify/latest/userguide/to-add-a-custom-domain-managed-by-a-third-party-dns-provider.html) |

**Recommendation for testing.** Try GitHub Pages first for the static site and docs. Compare Cloudflare Workers Static Assets if branch previews or traffic headroom become more important. A preview should prove deep links into versioned docs, search, correct links to a release, and the ability to redeploy a previous site build.

## Forum

GitHub Pages publishes HTML, CSS and JavaScript. A forum needs a service that handles sign-in, posts, persistence and moderation. The Community page can link to GitHub Discussions or to a standalone forum such as Discourse at `forum.tk-reawakened.com`. The website and forum can be hosted independently. An existing chat channel is another candidate for live conversation. Decide where durable help and playtest feedback should live and who moderates it before opening a new channel.
