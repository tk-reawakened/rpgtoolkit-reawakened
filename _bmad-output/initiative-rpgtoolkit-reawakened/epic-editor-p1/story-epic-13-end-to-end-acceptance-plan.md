## Intent

Exercise every P1 tool across its actual editor and runner integration after the sweep, including asset creation, board use, conversions and error recovery.

## Scope and acceptance

Trace each Done-when criterion and T-ID to explicit positive and negative cases, including shared-document identity, accessibility routes, save failure, retained originals, actual selected provider and truthful host capability; desktop runs only once its own host is available.

## Verification

A documented web and VS Code journey round-trips all P1 legacy assets, verifies sample-backed auto-tiling and overlay-free exports, and proves upgrades and failure paths preserve source.

## Dependencies and decisions

Prerequisites: 18, 12.1, 12.2. Apply the epic Notes, format specs, AD-18/19/20/22/29 and connected-authoring direction; CAP-16 maps to CAP-16. Preserve version and residue, use the existing shared model and browser, and route host access through platform-services. Where provider or host capability is unavailable, preserve data and report the limitation; do not simulate it.
