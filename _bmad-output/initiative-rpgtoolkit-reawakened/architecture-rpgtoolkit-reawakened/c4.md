## 4. Runtime flow: one advance call

```mermaid
sequenceDiagram
  participant R as Runner
  participant C as core Engine
  participant H as Host (assets, audio, saves)
  R->>C: advance(ticks, inputs {tick, event}[])
  C->>C: phases: input, waits, threads, events, movement, edges, triggers, battle, animation, audio, time
  C-->>R: TickReport (ticksRun, consumed, cues, requests with reqId, diagnostics, loading)
  R->>H: fetch assets and blobs, play cues
  H-->>R: bytes, ended events
  R->>C: advance(..., inputs incl. replies)
  R->>C: drawList(alpha)
  C-->>R: DrawList (blits reference surface and rev)
  R->>C: surfacePixels(id, rev) on cache miss
  R->>R: replay and present
```
