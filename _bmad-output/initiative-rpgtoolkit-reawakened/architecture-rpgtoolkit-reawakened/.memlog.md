- (decision) AD-5 clarified 2026-10-11 (ticket 2.21 ruling, written down docs-first for owner review): the asset key's case fold is ASCII-only — `A`–`Z` fold to `a`–`z` and every other code point is compared unchanged, after separators are normalised. Reason: the legacy platform folded with its upper-case table, in which U+212A maps to itself, so a Unicode lower-case fold both invents a collision Windows did not have (U+212A against ASCII `k`) and expands code points (U+0130 to i + U+0307); a full-Unicode fold also follows the runtime's Unicode tables, so two runners could key one project differently and disagree on a save hash (G3); and folding bytes above 0x7F would rest on the assumed Windows-1252 decode (§1.1). Cost, accepted: a reference that differs from the stored name only in the case of a letter above 0x7F no longer resolves (corpus evidence: 0 non-ASCII strings, 161/161 references match on disk exactly). The same fold covers the type-folder prefix, the `Game` first segment and the §1.6 extension match. format-spec §1.5 states the rule; the code half (foldPath, stripTypeFolder, projectFolder and the §1.6 extension match, plus the U+212A/U+0130 test) follows in its own commit, so until it lands the helper still calls toLowerCase.
- (decision) Supersedes AD-8 (ticket 3.3, 2026-10-15): the built-in contract is the functional command contract `call(view, args: Arg[], next) -> { value, out?, effects?, wait? }` — `view` is a read-only view of game state plus the injected rng/clock ports, a command mutates no state and reports what should happen as plain-data `effects`, `out` is the by-reference `[index, Value][]` the VM writes back, and `next` is the same name's definition in the layer below. The pure assembly function layers an ordered `PluginDefinition[]` (`{ id, version, commands }`): registration order is layer order and the later layer runs first, so a repeated name or alias is an override, not an error — exactly one `command.overridden` warning naming the previous and replacement plugins — and `next` where no lower layer defines the name returns the empty result (`value: null`) plus one `command.no-next` warning through the Logger port (AD-24).
