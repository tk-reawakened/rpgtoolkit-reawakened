## Intent

Entry 10.9 builds `packages/script-cli`, the `tkr script` command-line front end defined by TOOL-9 (`docs/spec/engine/rpgcode-tooling.md#tool-9`). It is one binary with five subcommands — `check`, `fmt`, `test`, `docs`, `index` — each producing the same `tkr-script-result/1` envelope, the four stable exit codes, and byte-stable `--json` output.

## Dependencies actually merged

- 10.4 (index) — `buildIndex` and `INDEX_SCHEMA` in `packages/script-tools/src/index-document.ts`.
- 10.6 (linter) — `lint`, `readLintConfig` and `RULES` in `packages/script-tools/src/lint.ts`.
- 10.7 (formatter) — `formatSource`, `formatChanged`, `formatCheck` in `packages/script-tools/src/format.ts`.
- 10.8 (runner) — the runner slice is merged as `d4e2d29f` but the story is still `status: blocked` on owner-gated matcher gaps.

## What this branch builds

- `tkr script check` — parser diagnostics plus lint over `.prg`/`.rnc` sources, honouring `tkr-lint.json`; lint findings retain their program path.
- `tkr script fmt` and `fmt --check` — rewrites or reports changes, refuses TK2.
- `tkr script index` — emits the TOOL-6 document; output is validated against the entry-4 schema.
- `tkr script docs` — emits a deterministic quick reference and searchable language reference from `commandDocumentation()`.
- `tkr script test` — drives the 10.8 runner over discovered `*.spec.prg` files; the passing dogfood project calls engine built-ins.
- `tkr-script-result/1` is validated against `docs/spec/schemas/tkr-script-result.schema.json` for every subcommand exercised.
- Stable exit codes 0–3; `--json` stdout is only the envelope, human-readable progress is on stderr, and internal errors retain the attempted subcommand.
- `script-dogfood` compares check, fmt, index, docs and test against committed baselines. It is a dependency of `gate`; the active `Gate Guards` ruleset requires `gate`.
- Fast-gate status (owner ruling 2026-11-12, [#2090](https://github.com/tk-reawakened/rpgtoolkit-reawakened/issues/2090)): `script-dogfood` is earlier feedback only. The "run only when RPGCode files change" criterion is deferred, not met; ADR 0016's fail-closed full gate is unchanged, and any faster required gate needs a separately approved dependency-aware classifier with proof of affected-job selection.

The CLI implementation originally merged in PR #1017 (merge commit 6b4357ed); this closeout adds the remaining behavior and evidence.
