## Scope

Connect current shipped help and generated reference to commands and settings, with plain-language-first descriptions, safe external links and coherent focus return.

## Acceptance

Missing documentation is identified, not faked; tutorial and tip-of-day presentation belong to Epic 14 while preference toggle belongs to 11.5.

## Verification

A creator opens help for a field, finds a built-in and inserts its documented syntax into the active program with keyboard-only navigation.

## Decisions and prerequisites

TOOL-7 reference generation provider is 10.9; no embedded obsolete browser is required.

Prerequisites: 11.4, 11.7, 10.9.
